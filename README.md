# 龙纹消消棋 🐉

> 三消 + 英雄技能 + 关卡战斗 + 轻 Roguelite 的 H5 竖屏网页游戏。
> 基于 **Vue 3 + TypeScript + Vite + Pinia** 构建，即点即玩、零后端依赖。

依据《龙纹消消棋-需求文档-V1.0》实现 **MVP 全量范围**：8×8 棋盘、6 元素、四消/五消技能石、3 名英雄、8 个遗物、第一章 10 关 + 第二章 5 关、3 种普通敌人 + 两阶段 Boss、3 关新手引导、结算与本地存档、核心爽感反馈。

---

## 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 启动开发服务器（http://localhost:5173，支持局域网真机调试）
npm run build    # 类型检查 + 生产构建（输出 dist/）
npm run preview  # 预览生产构建
npm run test     # 核心逻辑冒烟测试（42 项断言：棋盘引擎/数值公式/Boss 阶段/序列化）
```

> 生产构建体积约 **47 KB (gzip)**，无任何外部资源依赖（音效由 Web Audio 实时合成，图形全部 CSS/Emoji 实现）。

## 玩法速览

| 机制 | 说明 |
|---|---|
| 核心循环 | 交换相邻宝石 → 三消攻击 → 连锁掉落 → 敌人倒计时 -1 → 敌人行动 |
| 技能石 | 4 连 = 小技能石、5 连 = 终极技能石、L/T 型 = 炸弹石（3×3 连锁引爆）；点击技能石可主动释放（消耗 1 回合） |
| 英雄 | 1 主战（决定技能与元素 +20% 加成）+ 2 支援（提供被动）；MVP：炎龙骑士 / 冰霜女巫 / 森林德鲁伊 |
| 遗物 | 每波胜利后三选一，仅本关生效，最多 3 个，构建当局流派 |
| 敌人 | 行动倒计时制；精英（每 5 关）/ Boss（每 10 关，两阶段 + 阶段转换全屏攻击）；冰霜幽灵会冻结棋盘 2×2 区域 |
| 数值锚点 | 1 回合标准输出 = 10 伤害；连击倍率 1.0 → 3.0（6 连封顶）；每章宝石攻击 +1 |

### 关键设计决策

- **动画零 JS 开销**：64 个宝石 DOM 以 `cell.id` 为 key 复用，位置由 `transform: translate(%,%)` 表达，行列变化时 CSS transition 自动补间；新宝石入场与消除动画使用独立 `translate`/`scale` CSS 属性，避免与定位 transform 冲突。
- **消除流程可编排**：`标记 popping → 播放动画 → commitClear → gravity`，每个 async 步骤通过 `sleep()` 对齐动画时长，回合流程线性可读。
- **冻结宝石分段重力**：冻结宝石视为固定障碍，将每列切分为段；仅与棋盘顶部连通的段接收新宝石，段间空洞在解冻后自动恢复（REQ-ENEMY-101 悬空固定）。
- **洗牌收敛保证**：随机重排 + 贪婪修复（改写匹配组元素）双保险，确保洗后"无现成消除且存在有效交换"，避免死局循环。
- **存档快照化**：每回合结束将战斗全量状态（含棋盘 grid）序列化进 localStorage；刷新/退出后从主界面"继续战斗"无损恢复。

## 移动端适配与性能

- 竖屏单列布局（max-width 560px），`100dvh` + 安全区 `env(safe-area-inset-*)`
- `touch-action: none` 阻止棋盘滚动，Pointer Events 统一鼠标/触摸，支持点击与滑动两种交换手势
- 构建目标 `es2015`，Chrome/Safari/微信等主流移动浏览器兼容
- 动画全部 CSS 补间（transform/opacity/scale），无逐帧 JS；64 格响应式追踪开销可控
